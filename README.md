# hom — installeurs

Les versions publiées de hom, l'app qui aide à se sentir à la maison.

La dernière version est dans l'onglet **Releases** :

- `hom-mac.dmg` : Mac (Apple ou Intel, macOS 12 ou plus récent), ou `brew install hom-app/tap/hom`
- `hom-windows.exe` : Windows 10 ou 11 (64 bits)
- `hom-linux.tar.gz` : Linux et Raspberry Pi, installé par `curl -fsSL https://gethom.app/install.sh | sudo bash`
- `hom-box.img.xz` : l'image de la box hom, pour Raspberry Pi 4 ou 5

Le mode d'emploi est sur https://gethom.app. Le code de hom n'est pas publié ici : ce dépôt ne sert qu'à distribuer les installeurs.
